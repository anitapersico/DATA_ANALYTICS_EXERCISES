## Lesson 2 – Pandas Fundamentals

Exercise focused on the basics of data exploration and manipulation with **pandas**, using a training dataset (`training_data.csv`) containing workout session data (Duration, Date, Pulse, Maxpulse, Calories).

The exercise covers importing the dataset into a DataFrame, exploring its structure (shape, columns, data types, index), checking for missing values and duplicates, and selecting data with both `.loc` and `.iloc` through column selection and row slicing.
